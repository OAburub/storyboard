# Engagement Design for PPTX Lectures

How to design storyboard slides that motivate learners — not just inform them.

Read this before composing any PPTX lecture. Use alongside `slide-composition.md`
and `visual-grammar.md`.

---

## The Core Shift: From Information Delivery to Emotional Journey

Most PPTX lectures are designed like this:
```
WRONG: Slide 1: Title → Slide 2: Objectives → Slide 3-15: Content → Slide 16: Summary
       (information delivery = passive, forgettable, learner counts slides until it's over)
```

Engagement-designed lectures work like this:
```
RIGHT: "What question will haunt the learner until they find the answer?"
       → Build toward insight through curiosity, challenge, and discovery
       → Every slide serves the emotional arc, not just the information arc
```

---

## The Motivation Arc for Lectures

Every lecture (15-30 slides) should follow this emotional journey:

```
ENGAGEMENT
  ^
  |      IGNITE              TRIUMPH
  |     /  (curiosity         /  (mastery
  |    /    peaks)           /    moment)
  |   /                    /
  |  /   STRUGGLE         /     LAUNCH
  | /   /  (productive   /     / (transfer)
  |/   /    difficulty) /     /
  | HOOK              _/     /
  |  (grab)                 /
  +---------------------------→ LECTURE PROGRESS
  Sl.1-3  Sl.4-7  Sl.8-15  Sl.16-20  Sl.21-25
```

### Phase 1: HOOK (Slides 1-3)

**Goal:** Create an information gap. Make the learner NEED to know.

**Slide patterns that hook:**

| Pattern | Example | Visual Method |
|---------|---------|--------------|
| **Surprising statistic** | "73% of managers make this mistake daily" | `stat_cards` with bold number |
| **Provocative question** | "What would you do if this happened to your team?" | `content_slide` with large question text |
| **Real scenario** | "Last month, Company X lost $2M because..." | `content_with_cards` showing the situation |
| **Myth-buster** | "Everything you know about leadership is wrong" | `quote_highlight` with bold claim |
| **Visual puzzle** | Show a complex diagram — "By the end, you'll understand this" | `concept_visual` or SVG |

**What NOT to do:** "Welcome to Unit 3: Risk Management Procedures" — this hooks nobody.

**Gagne's Event 1 (Gain Attention)** should create CURIOSITY, not just get eyes on screen.

### Phase 2: IGNITE (Slides 4-7)

**Goal:** Build foundational understanding. Curiosity deepens as gaps expand.

**Slide patterns that ignite:**

| Pattern | Purpose | Visual Method |
|---------|---------|--------------|
| **Concept + Example** | Make abstract tangible | `two_column` (concept left, example right) |
| **Visual metaphor** | Connect new idea to known concept | SVG concept diagram or AI image |
| **Micro-check** | Quick low-stakes question to engage | `quiz` (not graded, just thinking prompt) |
| **Analogy bridge** | "Think of it like..." | `content_with_cards` comparing familiar → new |

**SDT alignment:** Quick wins build Competence. Connecting to prior knowledge builds Autonomy ("I already know something about this").

### Phase 3: STRUGGLE (Slides 8-15)

**Goal:** Productive difficulty. This is where real learning happens.

**Slide patterns for productive struggle:**

| Pattern | Purpose | Visual Method |
|---------|---------|--------------|
| **Scenario decision** | Apply knowledge under pressure | `scenario` interaction |
| **Process application** | Practice a procedure | `process_flow` with blanks to fill |
| **Comparison challenge** | Distinguish similar concepts | `comparison` with subtle differences |
| **Error analysis** | "What went wrong here?" | `content_slide` with flawed example |
| **Drag-and-drop** | Categorize, sequence, or match | `drag_drop` interaction |

**CRITICAL RULE:** Never go more than 3-4 content slides without an interaction. Passive slides kill engagement.

**Scaffolding:** Include hints in Storyline speaker notes. Some learners need support — don't let struggle become frustration.

### Phase 4: TRIUMPH (Slides 16-20)

**Goal:** The mastery moment. Learner demonstrates competence.

**Slide patterns for triumph:**

| Pattern | Purpose | Visual Method |
|---------|---------|--------------|
| **Culminating scenario** | Integrate everything learned | `scenario` with branching |
| **Before/after** | Show how much they've learned | `comparison` of pre vs. post knowledge |
| **Expert-level question** | Challenge at highest Bloom's level | `quiz` at Evaluate/Analyze level |
| **"Now YOU explain"** | Teach-back prompt | `content_slide` with reflection prompt |

### Phase 5: LAUNCH (Slides 21-25)

**Goal:** Transfer to real world. Anticipation for next unit.

**Slide patterns for launch:**

| Pattern | Purpose | Visual Method |
|---------|---------|--------------|
| **Visual summary** | Map of everything learned | `icon_grid` or SVG knowledge map |
| **Transfer prompt** | "Try this at work tomorrow..." | `content_slide` with action items |
| **Next preview** | Open a new information gap | `content_slide` teasing next unit |
| **Celebration** | Acknowledge achievement | `closing` with progress and encouragement |

## The Five Questions for Lecture Design

Before composing any lecture, answer:

### Q1: What should the learner FEEL during this lecture?

Choose 2-3 target aesthetics (MDA):

| Aesthetic | When to Choose It | Lecture Design Implication |
|-----------|------------------|--------------------------|
| **Challenge** | Skills training, procedures | Progressive difficulty, practice interactions |
| **Discovery** | Exploring new concepts | Revealing slides, "what if" prompts, branching |
| **Narrative** | Case studies, real-world application | Story arc across slides, characters, consequences |
| **Sensation** | When visual impact reinforces learning | Premium visual design, SVG metaphors, animation |
| **Expression** | Creative/leadership topics | Open-ended prompts, reflection, "your turn" slides |

### Q2: What's the learner's current motivation level?

| Level | What It Sounds Like | Design Response |
|-------|--------------------|-----------------|
| **Amotivated** | "I don't care about this topic" | STRONG hook. Lead with real-world consequences. |
| **External** | "My boss told me to take this" | Acknowledge reality. Make it painless. Quick wins. |
| **Identified** | "I know this is important for me" | Build on their motivation. Give depth and challenge. |
| **Intrinsic** | "I genuinely want to learn this" | Get out of the way. Provide depth, not hand-holding. |

### Q3: What RAMP balance fits this content?

| Content Type | R (Relatedness) | A (Autonomy) | M (Mastery) | P (Purpose) |
|-------------|----------------|--------------|-------------|-------------|
| Compliance | 20% | 10% | 30% | 40% |
| Technical skill | 10% | 25% | 45% | 20% |
| Soft skill | 30% | 25% | 20% | 25% |
| Academic | 10% | 30% | 35% | 25% |

### Q4: Where are the "Why This Matters" moments?

Plan at least ONE "Why This Matters" relevance block per section:
- Connect to the learner's actual job/life
- Show real consequences of not knowing
- Reference people they care about (team, clients, patients)

### Q5: Where is the culminating challenge?

Every lecture needs ONE moment where the learner proves mastery without scaffolding. Plan this before building any other slides.

## SDT in Slide Design

### Autonomy in PPTX

Since PPTX storyboards become Storyline 360 courses, you can design for autonomy:

| Technique | Storyline Implementation | Storyboard Notation |
|-----------|------------------------|-------------------|
| **Choose your scenario** | Branching slide with 2-3 options | Speaker notes: "BRANCH: learner selects scenario A, B, or C" |
| **Optional deep-dive** | Hidden layer revealed on click | Speaker notes: "OPTIONAL: click 'Learn more' for extended content" |
| **Self-paced review** | No forced navigation timing | Speaker notes: "NO auto-advance — learner controls pace" |
| **Skip if you know** | Pre-test gates content | Speaker notes: "If pre-test score >80%, skip to Slide X" |

### Competence in PPTX

| Slide Pattern | Competence Effect | When to Use |
|--------------|-------------------|-------------|
| `quiz` (easy) | "I already know something!" | Early in lecture (confidence builder) |
| `process_flow` | "I can see the steps clearly" | After teaching a procedure |
| `drag_drop` | "I can categorize this!" | After teaching classification |
| `scenario` (hard) | "I can handle complex situations!" | Near the end (mastery proof) |
| `stat_cards` (progress) | "I've come far!" | Summary slide showing growth |

### Relatedness in PPTX

| Technique | How to Design It |
|-----------|-----------------|
| **Real scenarios** | Use "you" and real workplace situations, not abstract examples |
| **Team framing** | "Your team depends on..." or "When your colleague asks..." |
| **Expert voice** | Quote from industry expert or practitioner |
| **"What would you do?"** | Invite personal reflection, not just correct-answer selection |
| **Social proof** | "87% of professionals in this field say..." |

## Visual Grammar + Engagement Mapping

When choosing visual patterns from `visual-grammar.md`, consider their engagement effect:

| Visual Pattern | Information Effect | Engagement Effect | Best For |
|---------------|-------------------|-------------------|----------|
| `process_flow` | Shows sequence/steps | Creates clarity → Competence | Teaching procedures |
| `stat_cards` | Highlights key numbers | Creates surprise → Curiosity | Hook slides, impact data |
| `quote_highlight` | Features expert insight | Creates credibility → Relatedness | Expert voice, inspiration |
| `timeline` | Shows progression | Creates narrative → Story flow | Historical context, project phases |
| `comparison` | Contrasts two things | Creates distinction → Understanding | Differentiating concepts |
| `icon_grid` | Organizes categories | Creates overview → Structure | Summarizing multiple items |
| `cycle_diagram` | Shows recurring process | Creates system thinking → Depth | Feedback loops, cycles |
| `concept_visual` | SVG/AI visualization | Creates "aha" → Discovery | Abstract concepts made tangible |

**Engagement principle:** Choose visual patterns that create EMOTIONAL connection, not just information clarity.

- `stat_cards` with surprising numbers → creates **curiosity** (Information Gap)
- `quote_highlight` with expert insight → creates **relatedness** (SDT)
- `concept_visual` with metaphorical SVG → creates **discovery** ("aha!")
- `comparison` with before/after → creates **triumph** (growth visible)

## Pacing Rules for Engagement

### The 3-4 Slide Rule

**Never go more than 3-4 content slides without an interaction.**

Passive slides in a row kill engagement. After 3-4 content slides, insert one of:
- `quiz` — Quick knowledge check (low stakes)
- `click_reveal` — Learner uncovers content actively
- `drag_drop` — Hands-on categorization or sorting
- `scenario` — Decision-making exercise
- `slider` — Rating or self-assessment
- Reflection prompt — "Pause and think about..."

### Cognitive Load Management

| Signal | Problem | Solution |
|--------|---------|----------|
| Dense text slide | Overload | Split into 2-3 simpler slides |
| Complex diagram | Processing strain | Build it progressively (reveal parts) |
| 3+ concepts per slide | Working memory limit | One concept per slide |
| 5+ content slides in a row | Attention fatigue | Insert interaction or "breathing slide" |

**Breathing slides:** Use `quote_highlight` or `concept_visual` between dense sections. These reduce cognitive load while maintaining emotional engagement.

### Variety Rule

Track content type distribution across the lecture:

```
GOOD distribution (25 slides):
  Content:     10 slides (40%)
  Interactions: 6 slides (24%)
  Visual/SVG:   4 slides (16%)
  Structural:   5 slides (20%) — title, objectives, dividers, summary, closing

BAD distribution (25 slides):
  Content:     18 slides (72%) ← PASSIVE OVERLOAD
  Interactions: 2 slides (8%)  ← NOT ENOUGH
  Visual/SVG:   1 slide  (4%)  ← BORING
  Structural:   4 slides (16%)
```

**Minimum interaction density:** At least 20% of slides should be interactive.

## Growth Mindset in Lecture Feedback

### Quiz Feedback Language

| Situation | Growth Mindset (use this) | Fixed Mindset (avoid) |
|-----------|--------------------------|----------------------|
| Correct | "Your reasoning is solid. You identified that [X] because [Y]." | "Correct!" |
| Correct on retry | "Persistence pays off! You adjusted your approach and found it." | "Finally correct." |
| Incorrect | "Not quite yet. The key insight is [X]. Try thinking about [Y]." | "Wrong. The answer is B." |
| Partial | "You're on the right track — you got [correct part]. Now consider [missing part]." | "Partially correct." |

### Instructional Language

| Purpose | Engagement Language | Disengaging Language (avoid) |
|---------|--------------------|-----------------------------|
| Introducing difficulty | "This next concept challenges even experts. Let's work through it together." | "This is basic and you should know it." |
| Transitions | "Now that you understand X, you're ready for the next level." | "Moving on to the next topic." |
| Effort acknowledgment | "Working through this material shows real commitment to your growth." | "You should find this easy." |

## Engagement Quality Checklist for Lectures

Run this on every PPTX lecture before delivery:

### Motivation Arc (all must pass)
- [ ] Opening creates curiosity or urgency (not "Welcome to Unit X")
- [ ] At least one "aha moment" designed into the lecture
- [ ] Culminating challenge near the end where learner proves mastery
- [ ] Closing connects to real-world application AND teases next unit

### SDT Compliance (at least 4 of 6)
- [ ] **Autonomy:** At least one choice point or branching path
- [ ] **Autonomy:** Language is invitational ("consider", "explore"), not controlling ("you must")
- [ ] **Competence:** Difficulty increases progressively through the lecture
- [ ] **Competence:** Feedback is specific and growth-oriented
- [ ] **Relatedness:** At least one real-world scenario from learner's context
- [ ] **Relatedness:** At least one "Why This Matters" relevance block

### Interaction Density (all must pass)
- [ ] No more than 3-4 content slides without an interaction
- [ ] At least 20% of slides are interactive (quiz, drag-drop, click-reveal, scenario)
- [ ] Visual pattern variety (not all content_slide — mix in stat_cards, comparison, process_flow)

### Flow Quality (at least 3 of 4)
- [ ] Lecture starts with achievable content (quick win)
- [ ] Difficulty escalates through the lecture (not flat)
- [ ] Scaffolding available for hard sections (hints in Storyline notes)
- [ ] Quiz questions escalate from Remember → Apply/Analyze

### Emotional Impact (at least 2 of 3)
- [ ] Lecture would make learner think "I didn't know that!" at least once
- [ ] Failure feedback encourages retry, not shame
- [ ] Learner ends feeling more capable than when they started

## Mapping Gagne's 9 Events to Engagement

Gagne's Events are already in `educational-standards.md`. Here's the engagement enhancement:

| Gagne's Event | Standard Approach | Engagement-Enhanced Approach |
|---------------|------------------|---------------------------|
| **1. Gain Attention** | Show title slide | Information Gap: surprising stat, provocative question |
| **2. State Objectives** | Bullet list of objectives | Frame as personal benefit: "After this, you'll be able to..." |
| **3. Recall Prior** | "You may already know..." | Quick quiz activating prior knowledge (Competence boost) |
| **4. Present Content** | Slides with information | Visual metaphors, stories, progressive reveal |
| **5. Provide Guidance** | Worked examples | "Think like an expert" — show expert reasoning process |
| **6. Elicit Practice** | Quiz at the end | Distributed practice throughout (the 3-4 slide rule) |
| **7. Provide Feedback** | "Correct/Incorrect" | Growth mindset: specific, encouraging, next-step oriented |
| **8. Assess Performance** | Final test | Culminating scenario integrating all concepts (Triumph phase) |
| **9. Enhance Retention** | Summary bullet list | Transfer prompt + visual summary map + next-unit tease |

## Information Gap Techniques for Slides

Based on Loewenstein's curiosity theory — create gaps between what learners know and want to know:

| Technique | How to Use in PPTX | Slide Type |
|-----------|-------------------|------------|
| **Open with a question** | "What causes 80% of workplace accidents?" | `content_slide` with large question |
| **Show partial data** | Reveal 3 of 5 factors, tease the remaining 2 | `icon_grid` with hidden items |
| **Myth-then-truth** | State common belief, then reveal it's wrong | `comparison` (myth vs. reality) |
| **Predict-then-reveal** | "What do you think happens next?" before showing result | `click_reveal` interaction |
| **Cliffhanger** | End a section with unresolved question | `content_slide` before section divider |

**The curiosity rhythm:** Open gap → Build tension → Fill gap → Open NEW gap → repeat

This rhythm sustains engagement across an entire lecture. Each section should end with a filled gap AND a newly opened one.
